# reto5-desarrollo-agil-uveg
Práctica de Git y GitHub para el Reto 5 de Desarrollo Ágil y Colaborativo de la UVEG


## Objetivo de la práctica
Demostrar el uso de Git y GitHub para el control de versiones y el desarrollo colaborativo.

## Actividades
- Sincronizar el repositorio con git pull.
- Registrar modificaciones mediante git add y git commit.
- Publicar los cambios en GitHub utilizando git push.
- Crear una rama de pruebas y fusionarla con main.
